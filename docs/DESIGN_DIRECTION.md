# Forklight Visual Direction

Engineering base: Grok 4.6 implementation.

The earlier Manus prototype is **visual reference only**.

## Keep

- dark industrial control-room / observatory tone
- MAIN/A/B/C immediately visible
- 3D warehouse dominant on screen
- right-side hard constraints and futures
- bottom real agent activity
- lock/protected indicators
- ghost original positions for branch diffs
- unmistakable `CAPABILITY UNLOCKED` moment

## Improve after live WebMCP works

- future cards show decisive four metrics directly
- A says `FAIL — DISTANCE`
- B says `VERIFIED`
- C says `FAIL — PROTECTED`
- smooth branch switching with fixed camera
- clear package flow/bottleneck without overbuilding graphics
- no visible QA controls in primary demo

## Avoid

- game-like decorative complexity that obscures concept
- Unreal-style graphics chase
- excessive bloom/noise
- template UI unrelated to Forklight
- hidden interactions the judge cannot understand in 3 minutes
