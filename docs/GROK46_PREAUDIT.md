
## Confirmed P1 WebMCP issue

`src/webmcp/toolWrapper.ts` currently JSON-stringifies outer tool results.

Target v1.2 behavior:

```ts
return { ok: true, ... };
```

not:

```ts
return JSON.stringify({ ok: true, ... });
```

Tests must change accordingly.

## Confirmed UI issue

`QaPanel` is rendered in the normal desktop layout and normal mobile tabs.

Target:

```text
default → hidden
?qa=1 → visible
```

## Positive correction vs Manus prototype

The Grok QA merge button already uses the registered/approved merge target rather than simply selecting the first verified branch. Preserve this semantic improvement.
